# 振り付け: v7 (2 曲目 candidate-4。決闘者) と v6 (1 曲目 candidate-2)
人間が遊んで不満を書くときの照合用。形式は docs/choreo-format.md。どちらも `scripts/validate-choreo.ts` で違反なし。タイトルでシーン (振り付け) を選べる (v7 T2。既定は v7)。

## v7 の狙い: 大技「三連突きからの大上段」を軸に、通常攻撃をそこから派生させる (docs/plan/v7-phase2-enemy.md「T4」)
本人の決め (2026-11-07、docs/decisions/song-choice.md「選択」): 2 曲目は candidate-4 (ドラムンベース風、右肩上がり、剣を持つ人型の決闘者)。「王道に強い敵が出てきそうで、差し込む隙が多くないから生き残りが基本目標」。本人の指摘 (2026-11-07): 「今の敵は追尾が弱くて、動いていると当たらない。連撃の中だけ追尾をきつく、踏み込みのある攻撃を」。
- 生成: `npm run gen:choreo-v7` (scripts/gen-choreo-v7.ts) が小節の型から v7.json を書く。65 攻撃 (melody 66 音 − 拍 0)、連撃の束 14、大技 3 (小節 7 / 15 / 23)。1 小節 = 1 フレーズ (phrase 番号 = 小節番号)。36 秒、敵 HP 40、反動耐性 0.6
- 大技 = 短い音の数だけ**突き** (段 1: 2、段 2: 3、段 3: 4。連撃 `group`。2 発目以降は当たりの 1 拍前に自機を狙い直す `aimBeat`) → 長い音で**大上段** (`heavy` の laser。長さ 0.6、太さ r 0.07、0.5 拍。紫。両手放ちだけで相殺、片手の放ちは軽減。slam と同じ規則)。突きの数が段で増えるのは曲の音型どおり
- 通常攻撃は大技の部品: 突き (短い laser。長さ 0.32、r 0.025) / 振り下ろし (大上段の小さい版。長さ 0.45、r 0.045。通常の相殺ができる) / 踏み込み突き (dash。v6 と同じ形) / 薙ぎ払い (sweep 120〜150 度、長さ 0.3。段 2 から。剣の振りが大きくなる) / 飛ぶ剣 (shot r 0.02。段 3 だけ。本人の「激しさが増すごとに剣を増やしてマジカルに」)

### 位置と動き
- 段ごとの構え G (x 0.60 / 0.58 / 0.56。段が進むほど前へ) と踏み込みの終点 L (G の 0.14 左)。y は小節ごとに 中央 / 上 0.09 / 下 0.09 を巡回
- 各攻撃の path は前の攻撃の path の終点から始め、小節の行動が終わったら次の小節の構えへ戻る (小節頭の 0.5 拍前に着く)。敵が飛ばないため。dash と approach は自機の位置で path が動くので、その後は次の攻撃の最初の点へ 1〜2 拍かけて滑る (v6 と同じ割り切り)
- 連撃の中で approach を使うと各発の JSON の位置と実際の位置がずれて敵が揺れるので、踏み込みは先頭の path に固定で書き、2 発目以降は L の 1 点。approach は単発の突き (段 1 の偶数小節) だけ

### 割り切りと気づき
- 150 度の薙ぎ払いは 1 拍前の狙い直しだと、近くにいる自機が横へ逃げ切れず `dodgeable` 違反 (走れる距離 0.18 に対し角度の外まで 0.2 超)。1.5 拍前にした。120 度 (段 2) は dash の行き過ぎた先から出すので狙いは予告開始のまま
- 立ったままだと段 1 の突きと dash で HP 5 が尽きる (sim-heavy.test.ts は HP を増やして大技だけを見る)。「生き残りが基本目標」の通りだが、難しすぎれば不満で
- 敵 HP 40 の理由: v6 (HP 12 / 14 攻撃) の比なら 56 だが、本人の「削り切れたらストーリーが変わるくらい」に合わせて削り切るのが難しい側に。v7 Phase 1 の既定 24 は「攻撃の数が倍」の読みで、実際は 4.6 倍だった
- shot / laser / sweep の `target` は自機の位置に置き換わるので、JSON の値 (自機の開始位置) は使われない

## v6 の狙い: Z モチーフを大技にし、攻撃を見分けられるようにする (docs/plan/v6-phase1.md、docs/plan/v6-phase2-enemy.md)
- 本人の指摘 (2026-11-04〜05): 「範囲攻撃前のレーザーは無くていい。関連のある新しい攻撃なら、飛び上がりと同時にレーザーの発射装置が 4 つ飛んでいき、範囲攻撃と同時に極太レーザーで逃げ場を狭める。両手の強い相殺を同時に当てたら相殺」「十字だと元の範囲攻撃が活きないので範囲攻撃を囲むように」「攻撃の判別がつきづらい。突進は狭い方向に動いてから来て何がしたいか分からない」
- v5 の 17 攻撃のうち Z (phrase 2, 5, 8) の laser 3 つを外し、burst を `slam` に替えた 14 攻撃。X と Y は v5 のまま。全て自機狙い (予告開始時の位置、追尾なし)。予告の先行は X / Y が 2 拍、slam は 2.5 拍 (1 音目から)
- 相殺不可 (赤) は無くなった。slam (紫) は両手放ちだけで相殺でき、片手の放ちは被ダメと吹っ飛びを 0.8 倍に軽減する。他の 11 (dash 3、shot 5、laser 3) は通常の相殺ができる (黄)。1 フレーズの 1 つ目の攻撃の予告の輪は二重 (2 連の印。X と Y)
- 反動耐性 `knockbackResist` 0.5: 両手相殺の反動 0.2 を、ジャストなら敵 2 : 自機 1 で分ける

## 経緯 (A → A' → v2 → v3 → v4 → v5 → v6)
A (v0。音の高低に敵の上下を合わせる) と B (拍の表裏で突進と弾) をサブエージェントが書き、B は「A と変わらない」で外した (git `53eb625`)。A' (a2) は v1 の比較用に A の補間を snap に、弾をレーザーに、叩きつけを音に合わせ直したもの。v2 は A' に自機狙いと相殺の属性を付けたもので、a.json と a2.json は 2026-10-27 に外した。v3 は v2 を等方座標に写し、当たりの r を見直したもので、v2.json は 2026-10-29 に外した。v4 は v3 に dash の分岐を付けたもので、v3.json は 2026-10-30 に外した。v5 は全メロディ音に攻撃を置いたもので、v4.json は 2026-11-02 に外した。v6 は v5 の Z を大技 slam に替えたもので、v5.json は 2026-11-05 に外した (git 履歴に残る。それぞれの狙いは外す前の assets/choreo/README.md)。
