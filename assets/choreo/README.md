## v5 の狙い: 曲のメロディの全ての音に攻撃を置く (docs/plan/v5-phase1.md、docs/plan/v5-phase2-enemy.md)
- 本人の指摘 (2026-11-02): 「1 小節に 1 回しか攻撃してこない今の形は普通に問題がある。構成も何も無い。メロディラインの全てに攻撃を配置していい」
- 18 音のうち拍 0 (phrase 0 の A♭4。予告の先行が取れない) を除く 17 音に攻撃。同じモチーフには同じ 2 攻撃。全て自機狙い (予告開始時の位置、追尾なし)。予告の先行は全て 2 拍。v4 の分岐の試し (dash の後に止まる) は外した (敵は止めない。本人)
- 相殺不可 (赤) は burst の 3 つだけ。他の 14 (dash 3、shot 5、laser 6) は相殺できる (黄)。1 フレーズの 1 つ目の攻撃の予告の輪は二重 (2 連の印)
- 敵の動き・拍・位置は v4 (= v3) の形を保ち、2 つ目の攻撃の単一キーフレームは外側の攻撃の同じ拍の位置に置いた

## 経緯 (A → A' → v2 → v3 → v4 → v5)
A (v0。音の高低に敵の上下を合わせる) と B (拍の表裏で突進と弾) をサブエージェントが書き、B は「A と変わらない」で外した (git `53eb625`)。A' (a2) は v1 の比較用に A の補間を snap に、弾をレーザーに、叩きつけを音に合わせ直したもの。v2 は A' に自機狙いと相殺の属性を付けたもので、a.json と a2.json は 2026-10-27 に外した。v3 は v2 を等方座標に写し、当たりの r を見直したもので、v2.json は 2026-10-29 に外した。v4 は v3 に dash の分岐を付けたもので、v3.json は 2026-10-30 に外した。v5 は全メロディ音に攻撃を置いたもので、v4.json は 2026-11-02 に外した (git 履歴に残る。それぞれの狙いは外す前の assets/choreo/README.md)。

## 共通の注意
- 初期位置 (0.25, 0.28) に立ち止まっていると 17 攻撃の全てが当たる (自機狙いなので、どこに立っていても止まっていれば当たる)。避けるには予告の間に動くか (ステップ)、接触の前後に向きを合わせて攻撃する (相殺)
- 連続攻撃の間隔は最短 1.5 拍 (Y の 4.5 → 6)。同時に 2 つを捌く場面は無いが、前の攻撃を捌いた瞬間に次の予告が出ている
