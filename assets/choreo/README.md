# 振り付け v2 (曲: candidate-2)
人間が遊んで不満を書くときの照合用。形式は docs/choreo-format.md。`scripts/validate-choreo.ts` で違反なし (自機狙いの `dodgeable` を含む)。
振り付けは 1 版 = 1 本で、タイトルに選択は無い (docs/plan/v2-phase1.md「2026-10-27 までに決まったこと」)。

## v2 の狙い: A' の振り付けに「自機狙い」と「相殺」を付けて、予測して捌く
- 動きと拍は A' (v1 で音に合わせ直した振り付け) のまま。変えたのは属性だけ
- dash と laser は `aim: "player"`: 予告開始 (telegraphBeat) の瞬間の自機の位置を狙う。追尾はしないので、予告を見て動けば避けられる
- 当たりの瞬間に、来る方向へ向けて攻撃すると相殺できる (向きの許容は src/config.ts `cancelFacingDeg`)。拍に乗せて出す必要がある
- burst は `aim: "player"` + `uncancelable: true`: 自機の位置に発生し、相殺できない。避けるしかない攻撃を混ぜて、全部を相殺で捌けないようにする

| phrase | モチーフ | type | 予告→当たり | aim | uncancelable | 一言 |
|---|---|---|---|---|---|---|
| 1 | Y | laser | 4→6 | player | - | 裏拍 4.5 で沈み、スネア (6) で上がりつつ自機へ射線。0.25 拍だけ判定。射線の向きの逆を向いて攻撃すると相殺 |
| 2 | Z | burst | 8→10.5 (+80 ms) | player | true | 72 で自機の少し上まで動き、無音は止まり、68 (10.5) のなり始めで叩きつけ、80 ms 後に r 0.22 の爆発。相殺不可 |
| 3 | X | dash | 16→18 | player | - | 68 で右上に構え、スネア (18) で自機へ斜めに落ちる突進。進行方向の逆を向いて攻撃すると相殺 |
| 4, 7 | Y | laser | 20→22, 36→38 | player | - | phrase 1 と同形 (始点だけ dash の着地点) |
| 5, 8 | Z | burst | 24→26.5, 40→42.5 (+80 ms) | player | true | phrase 2 と同形 |
| 6 | X | dash | 32→34 | player | - | phrase 3 と同形 |

モチーフ: X = phrase 0,3,6 (68→65)、Y = phrase 1,4,7 (63→65、裏拍から)、Z = phrase 2,5,8 (72→68 のあと 1 小節休み)。phrase 0 は攻撃なし。同じモチーフには同じ攻撃。

割り切り: 自機狙いで平行移動した戻りのキーフレームも同じだけ動くので、戻り先 (dash の着地点、burst の後の構え位置) は元と変わる。次の攻撃の始点へは攻撃間の補間で移る。laser の `target` は自機の位置に置き換わるので、JSON に書いてある (0.2, 0.43) は使われない。

## 経緯 (A → A' → v2)
A (v0。音の高低に敵の上下を合わせる) と B (拍の表裏で突進と弾) をサブエージェントが書き、B は「A と変わらない」で外した (git `53eb625`)。A' (a2) は v1 の比較用に A の補間を snap に、弾をレーザーに、叩きつけを音に合わせ直したもの。v2 は A' に属性を付けただけで、a.json と a2.json は 2026-10-27 に外した (git 履歴に残る。それぞれの狙いは外す前の assets/choreo/README.md)。

## 共通の注意
- 初期位置 (0.25, 0.5) に立ち止まっていると全攻撃が当たる (自機狙いなので、どこに立っていても止まっていれば当たる)。避けるには予告の間に動くか、当たりの瞬間に向きを合わせて攻撃する
- 連続攻撃の間隔は最短 3.5 拍で、同時回避の厳しさは無い。難しさは予告の読みと、拍に乗せた向き合わせに置いている
