# 振り付け v3 (曲: candidate-2)
人間が遊んで不満を書くときの照合用。形式は docs/choreo-format.md。`scripts/validate-choreo.ts` で違反なし (自機狙いの `dodgeable`、等方座標の `in-world` を含む)。
振り付けは 1 版 = 1 本で、タイトルに選択は無い (docs/plan/v2-phase1.md「2026-10-27 までに決まったこと」)。

## v3 の狙い: v2 と同じ振り付けで、相殺が「成立する」ようにする (docs/plan/v3-phase1.md)
- 動きと拍と属性 (自機狙い・相殺不可) は v2 のまま。変えたのは座標系と当たりの大きさと、相殺の窓
- 座標は等方の世界座標 (x 0〜1、y 0〜0.5625、単位は画面の幅)。v2 の y を 9/16 倍して写した。扇・当たり・本体が画面上で円と扇に見え、向きは画面上の角度で判定される
- 当たりの r: dash 0.03 (= 敵の本体の半径)、laser 0.02 (太さの半分)、burst 0.16。自機の半径は 0.024、敵は 0.03 (v2 の 0.6 倍)。自分の扇の半径は自機の直径 × 1.2 ≈ 0.058 (タイトルの調整パネルで動かせる)
- 相殺の窓は「自機との接触の瞬間」の前 100 ms・後 50 ms (既定。調整パネルで動かせる)。遅い側で相殺すると、受けた被弾は取り消される。dash の予告の輪は自機に届く瞬間 (突進の終点の拍) に収束する
- 相殺できる攻撃 (dash、laser) の予告は黄、できない攻撃 (burst) は赤

## 経緯 (A → A' → v2 → v3)
A (v0。音の高低に敵の上下を合わせる) と B (拍の表裏で突進と弾) をサブエージェントが書き、B は「A と変わらない」で外した (git `53eb625`)。A' (a2) は v1 の比較用に A の補間を snap に、弾をレーザーに、叩きつけを音に合わせ直したもの。v2 は A' に自機狙いと相殺の属性を付けたもので、a.json と a2.json は 2026-10-27 に外した。v3 は v2 を等方座標に写し、当たりの r を見直したもので、v2.json は 2026-10-29 に外した (git 履歴に残る。それぞれの狙いは外す前の assets/choreo/README.md)。

## 共通の注意
- 初期位置 (0.25, 0.28) に立ち止まっていると全攻撃が当たる (自機狙いなので、どこに立っていても止まっていれば当たる)。避けるには予告の間に動くか、接触の前後に向きを合わせて攻撃する
- 連続攻撃の間隔は最短 3.5 拍で、同時回避の厳しさは無い。難しさは予告の読みと、拍に乗せた向き合わせに置いている
