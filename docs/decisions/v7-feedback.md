# v7 の不満の分解と v7.1
本人の言葉 (2026-11-09、会話で。v7 T5 を見た直後): 「敵の動きがチープなのとプレイヤーの攻撃音が合って無さ過ぎてなんか恥ずかしくなってきました。まず、プレイヤーの攻撃音を電子音系に変えてほしいです。それと敵の攻撃の薙ぎ払い系とボールが飛んでくるようなエフェクトのやつが変な位置移動をしていているのですが意図的でしょうか？見てみてほしいです。ちょっとなんか中身をみられる状態じゃないので先に直してほしいです」。

## 分解
| # | 不満 | 原因 | v7.1 での扱い |
|---|---|---|---|
| 1 | 敵の攻撃 (薙ぎ払い、弾) の変な位置移動 | 意図的ではない。突進 (dash) の自機狙いの規則「予告開始より後のキーフレームを全部、着点が自機に重なるよう平行移動する」(v2 T4) に、v7 の path の置き方 (前の攻撃の終点から構え、出発の 0.5 拍前まで構えの位置にいる) が合っていなかった。v6 は予告の瞬間の点だけが固定で、予告 → 出発の 2 拍で構えへ動く途中が平行移動されていたので目立たなかった。v7 では予告の瞬間に構えの点ごと横へ跳び (`figure.html?beat=35.4` で敵が x 0.58 でなく 0.35 にいた)、着地後は次の攻撃 (薙ぎ払い) の JSON の位置へ 1 拍かけて歩いて戻ってから振っていた。弾 (段 3 の飛ぶ剣) の小節自体には跳びは無いが、直前の小節の薙ぎ払いの戻りと同じ型の動きが続いて見えた可能性がある | 直した (下) |
| 2 | プレイヤーの攻撃音が合っていない。電子音系に | 通常・ステップ・返し・相殺は v5 の撥弦 (pluck) のままで、2 曲目 (ドラムンベース風の電子音) と、放ち (歪んだ鋸歯) に対して浮いていた | 既定の音を assets/sound/v7.json にして電子音に (下) |
| 3 | 敵の動きがチープ | 具体は未聴取。姿 (duelist.ts) の鍵フレームの質、動きの補間、剣の見え方、予告の重なりのどれか | 先に 1 と 2 を直す (本人「先に直してほしい」)。何がチープかは不満ノートで聞く (NEXT.md「聞きたいこと」) |

## v7.1 で直したこと (2026-11-09)
- 振り付けの形式に 2 つ (docs/choreo-format.md「予備動作の固定と、前の攻撃の終点に続く」):
  - `windupFixed`: 自機狙い (dash / burst / slam) で動かすキーフレームを hitBeat より後に限る。出発点が固定、着点が自機。v7 の突進 7 つに付けた。v6.json は付けないので v6.1 の記録はそのまま
  - `followPrev`: 同じ group の直前の攻撃の (解決済みの) path の終点に、自分の path の最初の点を合わせて平行移動する (当たりの窓の終わりまでの点。戻りは動かさない)。sim が解決のたび (予告開始・狙い直し) に当てる。v7 の段 2 の「突進 → 薙ぎ払い」3 組に付け、着地した場所から振る。検査 `follow-shape` (group の 2 発目以降だけ)。`dodgeable` は JSON の位置で見る (approach と同じ割り切り。実際の発生点は突進の着地 = 自機の近く)
  - 確認: `figure.html?beat=35.4,36.3,37.2,38.2&py=0.12` で、予告の瞬間に敵が構えの位置 (0.58) にいて、着地した場所 (自機の左) から薙ぎ払い、戻りは構えへ。テスト sim-v7.test.ts (予告の前後で位置が跳ばない、薙ぎ払いの発生点 = 突進の終点、戻り先は JSON のまま)
- 音: 既定を assets/sound/v7.json に。通常 (表) = 矩形波の上がる滑り + 1 オクターブ上の短いサイン + 高域のクリック、通常 (裏) = 鋸歯でこもる (ローパス 3200)、通常 (外) = 下がる滑り (0.7 倍から) + 低いバンドパスノイズ、返し = FM (比 2、深さ 3) の「ピュン」+ 高い矩形波、ステップ = 高域ノイズの「タッ」+ サインの短い滑り、相殺 = 非整数比 (3.5) の FM の金属音 + 矩形波 + 高域ノイズ。放ち・両手放ち・溜めは v6 のまま (本人の言葉から作ったもの)。どれも 0.2 秒以内 (相殺は 0.37)。撥弦は使わない。v6.json は履歴として残す (sound.html で読み込めば戻せる)。本人が sound.html で作った音を貼れば差し替える
- 要約の先頭行は「音色 既定 (v7)」。自作の音を保存していた場合はそのまま自作が鳴る (既定に戻すのはタイトルでなく sound.html の「既定に戻す」)

## 学び
- 「敵の位置は path の点の間を補間する」仕組みでは、path の最初の点が自機狙いで動くと、前の攻撃の終点との間で跳ぶ。path を前の攻撃の終点から始める書き方 (v7) を採るなら、狙いで動かすのは出発以降だけにする必要があった。T4 の静止画の確認が大技の前後に偏っていて、突進の小節 (段 1 の奇数小節、段 2 の奇数小節) を見ていなかった。次からは figure.html の静止画で小節の型ごとに 1 つずつ見る
- 音は曲と一緒に聴かないと合っているか分からない。v6 で「不満が無かった」撥弦を v7 の曲に持ち越したのが外れた。曲が変わるときは音も見直す
