## 不満 → v4 の変更
| # | 不満 (要約) | 原因の読み | v4 の変更 |
|---|---|---|---|
| 1 | 相殺があることが何も生きていない。音楽に合わせて攻撃するよう誘導されてもいないし、意味もない。理想は、敵の曲は敵の行動を示し、プレイヤーの音は適切に動けているなら敵の曲に相乗りするメロディのような存在 (現実的か不安、音楽の知識が無い) | v0〜v3 は「捌けるか」までを作った。捌いた後に何も続かないので、相殺は孤立した 1 手。プレイヤーの音は拍の表裏で 3 種に変わるだけで、曲の音高とは無関係 | 「呼びと応え」を作る。敵のフレーズ (呼び) を捌いたら、その直後に応えの窓が開き、窓の間の拍に乗せた攻撃が曲の音階の音で鳴って敵に届く。音高は作曲ではなく、曲の調 (F マイナー) の 5 音から拍の位置と押した順で選ぶ (原本「攻撃のタイミングに合わせて鳴る音の高さが変わる」)。現実的かは v4 で 1 曲ぶん確かめる |
| 2 | 今は攻撃のタイミングだけが音楽に合っている。移動も合わせられたらいい。どこまで合わせるかは分からない (厳しすぎると何も作れず、合わなさすぎると BGM) | 移動は自由で、音との接点が無い | v4 では移動は自由のまま (入れないもの)。「応えの窓で敵が間合いに来る」ので、音に合わせる場面 (窓) と自由な場面 (読みと回避) が分かれる。移動そのものを拍に乗せる案は記録して後回し |
| 3 | 追いかけて攻撃する瞬間は面白くない。相殺や回避に何もリターンが無い (欲しいのはダメージや強化ではなく、アクション性) | 敵は休憩位置 (右端) に戻り、プレイヤーが歩いて寄って殴る。捌いても敵の挙動は変わらない | 捌けた (相殺した、または当たらなかった) 攻撃の後は、敵が自機の間合いまで寄ってきて応えの窓の間とどまる (追いかけない)。被弾したら寄ってこない。リターンは「応えの窓で攻撃できる」というアクションの続きで、ダメージの増減ではない |
| 4 | プレイヤーを人型に、敵を何かキャラクター性のあるものに | 四角と四角では、構え・攻撃・相殺・被弾・応えの状態が見分けられず、キャラへの関心も生まれない | 姿を最低限入れる: 自機は線で描く人型 (立つ・攻撃・相殺・被弾・応え、の構えが違う)、敵は性格のある 1 つの形 (攻撃の型ごとに構えが違う)。画像ファイルは使わず、線と面で描く。世界観 (背景・設定) は入れない。concept.md「入れないもの」の変更になるので本人の承認を取る (docs/plan/v4-phase1.md) |
| 5 | ここまで行くと Unity で作った方がいいのでは | 姿と動きを足すと、Canvas の手描きより既製のエンジンが楽に見える | v4 はブラウザのまま。理由と切り替えの条件は docs/plan/v4-phase1.md「エンジンの判断」。要点: 今の不満 (姿・応えの窓・音高) はどれも Canvas と Web Audio で届く範囲で、Unity に移すと「Claude が作って Chrome で確かめて URL を出す」回し方が数週間止まる。3D・物理・家庭用機への配置が要るときに移す |

## 記録して後回し (v4 の範囲外)
- 移動を拍に乗せる (拍で踏み込むステップなど)。応えの窓ができてから、移動が音と無関係なのが気になるかで決める
- Unity (または Godot) への移行。条件は v4-phase1.md
- 世界観・背景・ステージごとの雰囲気 (原本「hollow knight みたいな感じ」)。姿が入ってから
- 20 秒の終わり方、HP の意味 (docs/play-image.md 6 節 7)
- 音の出力遅延 280 ms への対策 (F6)。有線で変わるかを先に聞く。変わらないなら、押した瞬間に鳴る音を別経路で出す工夫 (難しい) か、音の遅れを前提にした設計を考える

## 仕組み側の学び
- 不満の中心が「判定の不具合」(v0〜v3。狩野モデルの当たり前品質) から「ゲームの骨格」(魅力品質) へ移った。docs/system-design.md「上に押し上げる力は出発点の要望の高さ」の段に入った。ここからは不満の分解だけでは足りず、docs/play-image.md のような「理想」の文書と照合して版の目的を決める
- 調整パネルは 1 周で役に立った (扇 1.6)。本人は既定から 1 項目しか動かさなかったので、項目は多すぎなかった
- 結果の要約の「音の出力遅延の補正」が本人の環境の問題 (280 ms) を見つけた。環境の値は要約に残しておく価値がある
- 不満ノートは自由記述で来た (4 行の型は使われていない)。分解はできたので、型の強制はしない
