# 音の仕様と音作りのページ (v6 T7〜T8。2026-11-05)
プレイヤーの音 (ステップ・通常・返し・放ち・両手放ち・相殺・溜め) は、行動ごとの「層の仕様」をデータで持ち、ゲームと音作りのページが同じ合成器で鳴らす。本人が音を作り、Claude は器を作る分担 (docs/plan/v6-phase1.md「音」、docs/decisions/v5-feedback.md 不満 4)。

## ファイルと場所
- 仕様の正本: `assets/sound/v7.json` (v7.1。2026-11-09 に既定を電子音にした。docs/decisions/v7-feedback.md 不満 2)。ゲームが読み込む既定の音。本人が作った JSON を Claude がここに入れて公開する。v6.json は v6 の既定 (撥弦) の履歴で、sound.html の「JSON を読み込む」で戻せる
- 型・既定値・範囲・正規化: `src/audio/soundspec.ts` (純粋関数。テストは soundspec.test.ts)
- 合成器: `src/audio/synth.ts` (`playSound` と持続音の `startSustained`)。`AudioEngine` (src/audio/engine.ts) が効果音と溜めの持続音をこれで鳴らす
- 音作りのページ: `sound.html` (src/sound.ts)。公開 URL の `/sound.html`
- 自作の音の保存先: ブラウザの localStorage `mal.soundBank` (src/ui/tuning.ts)。ゲームは開始のたびに読み、あれば既定の代わりに使う。要約の先頭行に「音色 既定 (v6)」か「音色 自作 (sound.html)」と出る

## 音の名前 (9 つ)
`step` ステップ / `normalOn` 通常 (表) / `normalOff` 通常 (裏) / `normalMiss` 通常 (外) / `riposte` 返し / `release` 放ち / `double` 両手放ち (2 つ目の放ち) / `cancel` 相殺 / `charge` 溜めの持続音。
基音 (Hz) は仕様に入れない。ゲームでは行動と拍の分類と音高の案 (src/audio/pitch.ts。案 1 コードの音 / 案 2 メロディをなぞる / 案 3 固定) で決まり、層はそこからの半音差で鳴る。相殺は最も近いメロディ音の 1 オクターブ上。両手放ちの基音は放ちと同じ。

## 層 (1 音に最大 4)
| 項目 | 意味 | 範囲 |
|---|---|---|
| `type` | `osc` 波形 / `fm` FM 合成 / `noise` ノイズ / `pluck` 撥弦 (v5 までの音) | |
| `gain` | 音量 (最大振幅)。持続音では上がり切ったときの音量 | 0〜1 |
| `semitones` | 基音からの半音差 (osc / fm / pluck) | −36〜36 |
| `wave` | 波形 (osc と fm の搬送波): sine / square / sawtooth / triangle | |
| `attack` / `hold` / `decay` | 包絡 (秒): 立ち上がり → 保持 → 指数の減衰。pluck は decay を音の長さとして使う (波形自体が減衰する)。持続音は attack だけ | 0〜0.5 / 0〜1 / 0.005〜2 |
| `sweepFrom` / `sweepSec` | 音高の滑り: 鳴り始めを基音の sweepFrom 倍にして sweepSec で基音へ。1 なら滑らない (osc / fm) | 0.25〜4 / 0.01〜1 |
| `lowpass` | ローパス (Hz)。20000 で無し (osc / fm / pluck) | 100〜20000 |
| `drive` | 歪み (tanh)。0 で無し (osc / fm / noise) | 0〜1 |
| `fmRatio` / `fmIndex` | 変調波の周波数比 (搬送波の何倍か) と深さ (搬送波の周波数の何倍まで揺らすか)。整数比でないと耳障りな響き | 0.25〜8 / 0〜10 |
| `noiseFilter` / `noiseHz` | ノイズのフィルタ (lowpass / highpass / bandpass) と周波数 | 100〜12000 |
| `pluckDecay` / `pluckBrightness` | 撥弦の 1 周期ごとの減衰と明るさ (src/audio/pluck.ts) | 0.8〜0.999 / 0.05〜1 |
| `gainAtStart` | 持続音 (charge) だけ: 溜め始めの音量。上がり切るまでに gain へ (進むほど層が足される音にできる) | 0〜1 |

無い項目は既定値、範囲外は端に収め、知らない項目は捨てる (`normalizeLayer`)。無い音は既定 (v6.json) で埋める (`normalizeBank`)。

## 持続音 (charge)
溜めが閾値 (0.5 拍) を超えたら始まり、放ちか解除で止まる (0.04 秒のフェード)。音高は音高の案の範囲 (案 1 なら F3 → F4) を `chargeFullBeats` (2 拍) で上がって保ち、層の音量は `gainAtStart` → `gain` を同じ時間で。手で区別しない (両手とも溜めても 1 つ)。音作りのページは「溜めの進み具合」のつまみで途中の音を聴ける (1.5 秒で止まる)。

## 同じ波形の保証
合成器は `BaseAudioContext` を受け、ゲーム (AudioContext) と音作りのページの波形描画 (OfflineAudioContext) で同じノードの組み方をする。乱数は使わない (ノイズは決め打ちの線形合同法、撥弦は前計算)。node のテストでは Web Audio が無いので、正規化と既定の音の値だけを見る (soundspec.test.ts)。波形は sound.html の「波形を描く」で目で見る。

## 音作りのページの使い方
1. 音の名前を選ぶ (放ちから始まる)。基音 (MIDI) は数値で動かせる (ゲームでは音高の案で決まる)
2. 層の種類とつまみを動かす。「鳴らす」で今の音、「曲の 1 小節と重ねる」で 1 小節目の 3 拍目に鳴らす、「波形を描く」で OfflineAudioContext の波形
3. 「この音をゲームに使う (保存)」で localStorage に保存。ゲーム (index.html) を開き直して遊ぶと使われる。「既定に戻す」で消える
4. 「JSON を書き出す」→「コピー」して不満ノートに貼るか vault に置く。Claude が `assets/sound/v6.json` に入れて公開する。「JSON を読み込む」で貼った JSON を取り込める

## Claude の初期値 (本人の言葉から。2026-11-05)
- 放ち: 歪んだ鋸歯 (ローパス 2500、歪み 0.6) をバックに、中音域 (基音 +27 半音 ≈ 830 Hz) のサインが 2.5 倍から 0.12 秒で下がるレーザー風、1 オクターブ下の「ドン」(2 倍から 0.08 秒で下がる)、高域ノイズの「スカン」(3000 Hz ハイパス、0.1 秒)。長さ約 0.35 秒 (「長くせず厚く」)
- 両手放ち: 同じ 4 層を厚く (音量と歪みを上げ、少し長く、ノイズは 1500 Hz のバンドパスに歪みを足す)
- 溜め: 鋸歯 + ローパス 1200 (v5 と同じ) に、溜めが進むと 1 オクターブ下の FM (比 1.41、深さ 2.5、ローパス 900) が 0 から 0.06 まで足される (「ギリギリするような力いっぱい溜めている感じ」の初期値)
- ステップ・通常・返し・相殺: v6 までは v5 の撥弦の値を 1 層で保っていた。v7.1 で電子音に (本人「攻撃音を電子音系に」): 通常 (表) = 矩形波の上がる滑り (1.5 倍から 0.03 秒) + 1 オクターブ上の短いサイン + 高域のクリック / 通常 (裏) = 鋸歯でこもる (ローパス 3200) / 通常 (外) = 下がる滑り (0.7 倍から) + 低いバンドパスノイズ / 返し = FM (比 2、深さ 3) の「ピュン」+ 高い矩形波 / ステップ = 高域ノイズの「タッ」+ サインの短い滑り / 相殺 = 非整数比 (3.5) の FM の金属音 + 矩形波 + 高域ノイズ。どれも 0.2 秒以内 (相殺 0.37)
