## T1 (候補 3 曲の生成と candidates.html)
### 共通の形
- 4/4、24 小節 = 3 段 × 8 小節。BPM は 150〜160 で 36〜38 秒。トラックは `melody` (主旋律。攻撃の元)、`lead-high` (背景の高音の線。最初から鳴り、段が変わっても音型を変えない)、`bass`、`drums`
- `melody` の音の始まりは全部 8 分の格子 (0.5 拍の倍数) に置く。当たりは 8 分の格子に乗る決まり (acceptance `gridSubdivision` 2) なので、3 連や付点の跳ねは drums と bass にだけ入れる
- `melody` は 1〜2 小節ごとに 1 拍以上の休符を置き、フレーズが 2 小節を超えないようにする (grid.ts は休符 1 拍で切る。「同じフレーズには同じ攻撃」の予測を作るため)
- 各段の最後の小節 (小節 8、16、24) に、その敵の大技の音型を置く (段が進むほど速く・多く)。大技は複数の音で 1 つの攻撃 (予告の音 + 当たりの音)
- `lead-high` は正弦波に近い柔らかい声 (engine に `lead` の声を足す。軽いビブラート、小さめの音量)。「抜けのいい高音」に寄せるが、音色の追求はしない (concept「曲の個性の追求」は入れない)

## T2 (シーンの選択とタイトル・要約の先頭行)
- 今の仕組みで既に、assets/choreo/*.json が 2 本以上あればタイトルに選択カードが出て、カードごとに曲を読む (src/main.ts)。足りないのは「シーンごとの長さと敵の HP」と「既定の選択」
- Choreo に任意の `sceneSeconds` と `enemyHp` を足す。main.ts は開始時に acceptance の `sceneSeconds` と cfg の `enemyHp` をその値で上書きする (acceptance.json と config.ts の既定は変えない。v6.json は書かないので v6.1 と同じ)
- タイトル: カードに「曲: X / N 秒 / 敵 HP」を出す。既定の選択は最後のカード (id 順で最新 = 2 曲目)。選択は localStorage (`mal.scene`) に残す
- 要約の先頭行は今のまま (振り付け id と曲 id が出る)
- テスト: Choreo の sceneSeconds / enemyHp で sim の終了時刻と敵 HP が変わること (sim のテスト)。無ければ既定

## 既定値 (Claude の決め)
| 項目 | 既定値 | 理由 |
|---|---|---|
| 段の切り替わり | 小節 9 と 17 の頭 | 8 小節 × 3。拍に乗せる |
| lead-high の音域と音量 | MIDI 84〜91 (C6〜G6)。engine の `lead` 声は正弦波 + 5.5 Hz のビブラート、音量 0.09 | 主旋律 (矩形波、音量 0.12) より上の音域で薄く。「後ろで鳴る」 |
| 大技の音型の置き場 | 各段の最後の小節 | 段の締めに象徴の行動。3 回出るので予測が作れる (song-choice.md の方針) |
| melody の音数の目安 | 4: 12 / 20 / 28、5: 12 / 26 / 6 + 5、6: 14 / 22 / 30 (段 1 / 2 / 3) | 1 曲目 (14 音 / 20 秒) の密度を段 1 で保ち、激しい段で 2 倍まで。連撃が吸収する前提 |
