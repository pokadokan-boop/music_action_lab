# v5 計画 Phase 2 (セッション A): プレイヤーの行動
作成 2026-11-02。Phase 1 (docs/plan/v5-phase1.md、承認済み 2026-11-02) の T1〜T5 の詳細と既定値。承認は要らない (CLAUDE.md「承認の扱い」)。接頭辞は `[作品]`。セッション B (敵の配置) は docs/plan/v5-phase2-enemy.md。

## 入力 (T1)
- `InputState` に `dodgePressed?: boolean` (押している間 true。省略は false)。`attackPressed` は今と同じ「押している間 true」で、sim が立ち上がり (押した瞬間) と立ち下がり (離した瞬間) を `attackLatch` で取る
- DualSense: 攻撃 R1 = `buttons[5]`、回避 ○ = `buttons[1]`。× (`buttons[0]`) は決定 (confirm) だけに残す。キーボード: 攻撃 J / Space、回避 K
- 理由: 親指で ○ を押しながら人差し指で R1 を押し続けられる (本人の指定)

## プレイヤーの状態 (sim)
| 状態 | 中身 | 変わるとき |
|---|---|---|
| `stepping` | `{ startBeat, dir }` | 回避の押下で始まり、`stepBeats` (0.5 拍) で終わる。始まって `stepRetriggerBeats` (0.25 拍) 以上たてば次の押下で新しいステップに置き換わる (16 分の連打「タタンッ」のため) |
| `charge` | `{ startBeat, armed }` | 攻撃の押下で `startBeat` を置く。押したまま `chargeThresholdBeats` (0.5 拍) を超えたら `armed` (溜め状態。持続音が始まる)。離した瞬間に armed なら放ち。被弾で null (解除。armed なら `charge-break` を記録し持続音を止める)。解除後は離して押し直すまで溜め直せない |
| `lastCancelBeat` | 直近の相殺の拍 | 相殺が成立するたびに更新。返しの窓の基準 |

## 行動 (T1〜T3)
| 行動 | 入力 | 動き | 判定 | ダメージ | 記録 (`kind`) |
|---|---|---|---|---|---|
| ステップ | 回避の押下 | スティックの向き (無入力なら敵と逆) へ `stepDistance` (0.18) を `stepBeats` (0.5 拍) で等速。ステップ中はスティックの移動を無視。無敵なし。溜めは切れない | 16 分の格子 (0.25 拍) に ±`stepWindowMs` (40 ms) で「乗った (on) / 外 (miss)」 | - | `step` (cls, offsetMs) |
| 通常攻撃 | 攻撃の押下 | 今のまま (扇、寄せ) | 今のまま (表 / 裏 / 外、8 分の格子 ±0.125 拍) | 1 | `attack` (action `normal`) |
| 返し | 相殺から `riposteWindowBeats` (1 拍) 以内の攻撃の押下 | スティック入力があればその向きへ `lungeDistance` (0.1) 踏み込んでから扇の判定。無入力なら踏み込まない。相殺の判定も持つ (踏み込みの前の位置で) | 通常と同じ | 1 | `attack` (action `riposte`, lunge) |
| 溜めの放ち | 溜め状態で攻撃を離す | 扇は通常と同じ。相殺の判定も持つ | 通常と同じ | 3。相殺が成立すれば「強い相殺」として 3 (扇にも入っていても二重にしない) | `attack` (action `release`, strong) |
| 溜め | 押し続けて閾値を超える | 動ける、ステップできる | - | - | `charge` (閾値を超えた拍)、`charge-break` (被弾で解除) |

- 押下は常に「通常攻撃 (または返し) + 溜めの開始」。放ちは離した瞬間
- `hit` に `damage` (1 / 3)、`cancel` に `strong` (放ちによる相殺) を足す
- 返しの踏み込みは瞬間移動 (0.1 を一歩で)。今の寄せ (扇の中なら接触距離まで寄る) も瞬間なので、同じ扱い。滑らかにするのは不満が出てから

## 音 (T4)
- 音色 (src/audio/pluck.ts の `PluckKind` に足す。全て撥弦の系統で、曲の 3 声 (矩形・三角・ノイズ) と別): `step` = 短い打音 (0.08 秒、鈍い、小さめ)、`riposte` = 短く高く明るい (0.15 秒)、`release` = 長く低い (0.8 秒、明るさ 0.6)。`on` / `off` / `miss` / `cancel` の既定は v3 のまま (テストで一致を見る)
- 溜めの持続音: engine の `startCharge(atSec)` / `stopCharge(atSec)`。鋸歯状波 + ローパスで、`chargeFullBeats` (2 拍) かけて音高が 1 オクターブ上がり切って保つ。音量は小さく (0.08)。曲の矩形・三角と区別できる
- 音高の規則 (src/audio/pitch.ts、純粋関数 `pitchFor(action, cls, beat, grid, rule)` → MIDI 番号): 3 案。タイトルで選び、localStorage `mal.pitchRule` に保存、要約の先頭行に「音の案 n」

| 行動 | 案 1 chord (コードの音。F マイナー: F / A♭ / C) | 案 2 motif (その拍に最も近いメロディ音 m) | 案 3 fixed (v3 の値) |
|---|---|---|---|
| 通常 表 | F5 (77) | m + 12 | A5 (81 = 880 Hz) |
| 通常 裏 | C5 (72) | m | A4 (69 = 440 Hz) |
| 通常 外 | F2 (41、鈍い) | m − 24 (鈍い) | A2 (45 = 110 Hz) |
| ステップ | C5 (72) 乗った / A♭4 (68) 外 | m 乗った / m − 12 外 | A4 (69) / A3 (57) |
| 返し | A♭5 (80) | m + 12 + 3 (短 3 度上) | C6 (84) |
| 放ち | F3 (53) | m − 12 | A3 (57) |
| 相殺 | 今のまま (m + 12) | 今のまま | 今のまま |
| 溜めの持続音 | F3 → F4 | m − 12 → m | A3 → A4 |

- 案 1 は F マイナーの主和音だけなので、どの拍で押しても曲と喧嘩しない。案 2 は曲のメロディをなぞる。案 3 は v3 と同じ (比較の基準)。既定は案 1
- 音楽として良いかは Claude が判定しない。3 案を聴いて本人が選ぶ

## 記録と要約 (T5)
- `attack` イベントに `action` (`normal` / `riposte` / `release`)、`lunge` (返しの踏み込みの有無)、`strong` (放ちで相殺)。`step` イベント (cls `on` / `miss`、offsetMs)。`charge` / `charge-break` イベント
- 要約に足す行:
  - `行動: ステップ n 回 (乗った m) / 通常 n (表 a 裏 b 外 c) / 返し n (表 a 裏 b 外 c、踏み込み k) / 放ち n (表 a 裏 b 外 c)`
  - `溜め n 回 (放ち m / 被弾で解除 k) 強い相殺 s 回`
  - 「プレイヤーの譜」: 1 行 1 小節、16 分の格子 16 マス、1 拍ごとに空白で区切る。記号: ・ 無し / ス ステップ / 攻 通常 / 返 返し / 放 放ち / 溜 溜め中 / 相 相殺した押下 / 強 強い相殺。同じマスに複数あれば 強 > 相 > 放 > 返 > 攻 > ス > 溜 の順に 1 つ。凡例を 1 行添える
- 既存の行 (攻撃 n 回 (表, 裏, 外) 命中、向き、相殺、捌けた、拍とのズレ、被弾) はそのまま。「攻撃」は通常・返し・放ちを全部含む (押下の総数として今までと比べられる)
- phrase 表の「2 音目」の列はセッション B で (攻撃が 2 つになってから)

## 構え (T5)
- 自機の構えに `step` (前傾して脚を伸ばす)、`charge` (腰を落として両腕を後ろに引く)、`release` (両腕を前へ大きく振り切る)、`riposte` (低く突く) を足す。優先順: 被弾 → 相殺 → 放ち → 返し → 攻撃 → ステップ → 溜め → 構える → 立つ
- 溜め中は自機の周りに細い輪 (半径が 2 拍で 1.2 → 1.8 倍)。判定の形ではなく状態の印なので、判定の規律 (描画 = 判定) には触れない。色は自機の色を薄く
- 敵の構えは変えない

## 既定値 (src/config.ts に足す。理由)
| 項目 | 値 | 理由 |
|---|---|---|
| `stepBeats` | 0.5 | Phase 1 |
| `stepDistance` | 0.18 (自機の直径 0.048 の 3.75 倍) | 1 歩で burst の半径 0.16 の中心から外へ出られる。速さは 0.84/秒で素の移動 (0.6) の 1.4 倍。Phase 1 の 0.14 では素の移動と差が無かった (0.5 拍の歩きが 0.128) |
| `stepRetriggerBeats` | 0.25 | 16 分の連打を受け付ける |
| `stepWindowMs` | 40 | 16 分 (107 ms) の間隔に対して ±40 ms |
| `chargeThresholdBeats` | 0.5 | Phase 1 |
| `chargeFullBeats` | 2 | 持続音が上がり切る長さ。上限は無い |
| `riposteWindowBeats` | 1 | Phase 1 |
| `lungeDistance` | 0.1 (直径の 2 倍) | ステップより短く、間合いの調整用 |
| `damage` | normal 1 / riposte 1 / release 3 | Phase 1。敵 HP 12 |

## テスト (全て sim を直接回す。Chrome の自動操作は時刻の検証に使えない)
- ステップ: 0.5 拍で 0.18 動く、スティック無入力なら敵と逆、ステップ中はスティックを無視、0.25 拍後の押下で置き換わる、16 分の判定 (乗った / 外)、溜め中にステップしても溜めが残る
- 溜め: 閾値未満で離すと何も起きない、閾値を超えると `charge` が記録される、離すと `attack` (release) と敵 HP −3、被弾で `charge-break` と解除 (その後離しても放たない)
- 強い相殺: v4.json の dash を放ちで相殺すると `cancel` (strong) と敵 HP −3、通常の相殺では敵 HP が減らない
- 返し: 相殺から 1 拍以内の押下は `riposte`、1 拍を過ぎると `normal`。スティック入力があれば 0.1 踏み込む、無ければ動かない
- 音高: 3 案 × 行動の表 (上) が返る。`fixed` は v3 の Hz に一致
- 要約: 行動の行、溜めの行、譜の行 (記号と優先順)
- 構え: 優先順
- 既存の 150 件が通る (InputState の `dodgePressed` は省略可)

## 実装で決めたこと (2026-11-02)
- ステップの終わり: 押した step は素の移動をしてから始まり (開始は移動の後)、以後 stepBeats ぶんの step (120 Hz で 30 step) で stepDistance をちょうど動き、その次の step から素の移動。終了判定は `beat − startBeat > stepBeats`
- 放ちのダメージは 1 回だけ: 強い相殺が成立したら敵 HP −3 を入れ、扇に敵が入っていても hit は記録しない (二重にしない)。強い相殺のダメージは cancel (strong) に付随し、hit イベントにはならないので「命中 n」には数えない。「強い相殺 n 回」で見る
- 返しの踏み込みは瞬間移動で、相殺の判定 (押した位置) の後、扇の判定の前に行う
- 溜めの持続音は engine の 1 本だけ (startCharge で置き換え)。ゲーム終了時にも止める
- 溜めの輪は自機の色で alpha 0.35 → 0.7、半径は閾値を超えてから chargeFullBeats で 1.2 → 1.8 倍
- 譜の丸めは最寄りの 16 分 (Math.round)。小節数は grid.totalBeats / beatsPerBar の切り上げ
- 音の案の既定は chord。保存キー `mal.pitchRule`
