# 最初の実験のコンセプト
ゲームのアイデア原本は vault の `音楽アクション/` にある (入口は vault:音楽アクション/入り口.md)。この文書は、最初の実験で扱う範囲だけを決める。原本の中身は写さず、どの要素を使うかと出典の見出しだけを書く。

コンセプトは保護対象。自律で直す修正がここに書いた要素を侵すなら、その修正は棄却する (docs/system-design.md「「不満」と「感性」の切り分け」)。保護対象は「範囲」「取り入れる要素 (保護対象)」「曲」の 3 節。「初期案」の節は手触りの不満に応じて変えてよい。

## 範囲 (2026-10-21 確認)
- 20 秒の戦闘シーン 1 つ。敵 1 体、曲 1 つ
- 最終的にはコントローラー (DualSense) で遊ぶ。手触りを確かめやすくするため、最初はブラウザで作る
  - PC のブラウザは Gamepad API で DualSense を標準ゲームパッドとして読めるので、v0 からコントローラーで遊ぶ。キーボードは代替入力
  - DualSense 固有の機能 (ハプティクス、アダプティブトリガー) は標準の Gamepad API では使えない。使いたくなった時点でブラウザ外の形を検討する
  - スマホのブラウザで遊べることは必須にしない。スマホは反応と不満を返す側に使う
- ジャンルは格闘ゲームに近いアクション。シューティングではない。近い参照は東方の格ゲー (浮遊する横視点の 1 対 1)。スマブラの座標とアクションの重視も好みだが、優先順位は音楽との親和性が最上位 (vault:音楽アクション/入り口.md 12 行目「音楽要素 + アクションのコンセプトを邪魔して欲しくない」)
- 確かめる焦点はゲームの手触り

## 取り入れる要素 (保護対象。2026-10-21 確認)
- 横視点の 2D (vault:音楽アクション/根本コンセプトアイデア.md「基本的な画面イメージ」)
- 敵が曲に合わせて行動する (vault:音楽アクション/入り口.md 冒頭)
- テンポと拍子を、敵や自キャラの動きから常に把握できる (根本コンセプトアイデア「どの方向でも入れたいもの > テンポ把握」)
- プレイヤーの行動が音楽の一部になる。最小形は、攻撃したタイミングの拍の位置で鳴る音が変わる (同「どの方向でも入れたいもの > ユーザーの行動が音楽になる」)

## 初期案 (制約として残さない。手触りの不満で変えてよい。2026-10-21 確認)
- 攻撃予告に、拍の数に合わせた補助線を入れる (根本コンセプトアイデア「攻撃予告を入れるなら」)。まず原本どおり試す
- HP バーは主張させない (同「基本的な画面イメージ」)。邪魔でなければ形は問わない
- 重力をあまり気にしない移動と、射程内なら当たるように少し補正する (vault:音楽アクション/入り口.md の座標要素の段落)
  - v0 は常に浮いている (ジャンプ無し) で始める。地上と空中の 2 状態を作ると入力・当たり判定・敵の攻撃設計が倍になり、20 秒・敵 1 体の範囲では地形利用の出番も無いため
  - 常に浮いているのは東方の格ゲーの空中戦に近く、ジャンル参照と矛盾しない。弱点は、地面の無い 1 対 1 ではスマブラ的な立ち位置の読み合いが薄くなりうること。不満として出たら、ジャンプ有りの版との 2 案比較で確かめる

## 曲 (この対話で決定)
- 仮置き。AI が候補を複数出し、自分は選んで理由を一言返す。作曲はしない
- MIDI を正本にする (docs/feasibility.md「実現可能性のフック」)
- 曲の条件は vault:音楽アクション/音楽参考.md の言葉を使う: かっこよくてゆっくり / 4 拍子で 8 連打ではなく 4 音 / 構成要素が少ない
  - これらは探すときの目安であり必須条件ではない。機械判定も合否条件も置かない。BPM で縛らない (2026-10-21)
  - 「ゆっくり」は BPM ではなく音の密度 (1 小節 4 音) を指す。遊ぶのが当面本人だけなので、BPM が高くてかっこいい方が嬉しい (2026-10-21)
- v0 の曲は candidate-2 (トラップ風ハーフタイム、140 BPM)。選択の理由と、そこから見えた方向 (フレーズを骨格にして予測と捌きを作る) は docs/decisions/song-choice.md (2026-10-22)
- 敵の攻撃は MIDI から機械的に作らず、「このフレーズでこの攻撃をしたらかっこいい」を拍グリッドに振り付けたデータとして書く。かっこよさの判定は人間の不満に置き、機械は可読性と公平さ (予告の先行、当たりがグリッド上、避けられる位置) だけ検査する (2026-10-21)

## 最初の実験に入れないもの (2026-10-21 確認)
- 世界観・キャラデザ (原本でも後回しとされている)
- 難易度選択と難易度調整変数 (根本コンセプトアイデア「難易度調整変数」)
- ボス、複数ジャンルのフレーズ重ね (vault:音楽アクション/入り口.md)
- 1 曲に複数のアクションを作り合体させる構成 (vault:音楽アクション/1つ曲に対して複数のアクションを作る.md)
- 曲の個性の追求
